## Hello World Program

### Introduction

The **Hello World program** is one of the simplest and most common programs used when learning a new programming language. It is usually the first program beginners write because it helps us understand the basic structure of a program and how to display information on the screen.

In Python, we use the **`print()` function** to display text or other information as output.

### Basic Syntax

```python
print("Hello, World!")
```

### How It Works

* `print()` is a built-in Python function used to display output.
* `"Hello, World!"` is a **string**, which means a sequence of characters.
* The text inside the quotation marks is displayed on the screen.
* Python executes the statement from left to right and produces the output.

### Example

```python
print("Hello, World!")
```

### Output

```text
Hello, World!
```
